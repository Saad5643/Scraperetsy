Etsy Scraper

If something goes wrong

The download was blocked or deleted

Browsers and antivirus tools treat unsigned .cmd files as suspicious by default. In Chrome, open chrome://downloads, find the file and choose Keep dangerous file. In Edge, open the Downloads panel and choose Keep.

Double-clicking opens Notepad instead of running

The file was saved as text. Check that the name ends in .cmd and not .cmd.txt — in File Explorer turn on View → Show → File name extensions to see the real ending, then rename it.

"No such file or directory"

The file is not where the command expects. If your browser saved it somewhere other than ~/Downloads, use the real path instead — or drag the file into the terminal window after typing bash and a space, which pastes its path for you.

macOS says it cannot be opened

That is Gatekeeper reacting to a downloaded file, and it only applies to double-clicking. Running it with bash ~/Downloads/install-etsy-scraper.sh as in step 2 avoids it — you do not need to change any security settings.

The browser will not start after installing

Chromium needs a handful of system libraries that only a package manager can install. Run this once, then start the app again:

cd ~/etsy-scraper/scraper && sudo npx playwright install-deps chromium

It says the installer looks damaged

The file did not arrive whole — usually an interrupted download, or a chat app that mangled it on the way. Download it again from this page.

Setup stopped partway through

The real reason sits a few lines above the red message, and a dropped connection is the usual one. Just run it again: every finished step is skipped, so it picks up where it stopped. Your settings and anything already scraped are never overwritten.

Nothing happens when I open the shortcut

If Node.js was installed during setup, the very first launch can miss it. Close the console window and open the shortcut again.

If the app is already running, the shortcut just reopens the browser tab rather than starting a second copy.

Etsy is blocking the scraper

Installing Google Chrome helps — the uploader prefers real Chrome and falls back to a bundled browser. Slowing down and scraping fewer listings per run helps more.
